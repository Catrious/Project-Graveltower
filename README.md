# Project-Graveltower
The reverse of Project Sandcastle, iOS on Android devices <br>
NOTE: It is still in private beta, the launch is unknown but the full thing will be released in June 15th-July 7th. <br>
REQUIREMENTS: <br>
QEMU <br>
A PC with ADB <br>
A rooted phone with a Qualcomm Snapdragon 845 processor (test CPU with CPU-Z) <br>
<br>
SETUP: <br>
1. Run ```fastboot flashing unlock``` <br>
2. Run ```fastboot flash recovery graveltower.img``` <br>
3. Run ```fastboot boot graveltower.img``` <br>
Now iOS is running on your phone! <br>
