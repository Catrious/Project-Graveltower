The reverse of Project Sandcastle, iOS on Android devices <br>
NOTE: It is still in private beta, the launch is unknown but the full thing will be released in June 15th-July 7th. <br>
REQUIREMENTS: <br>
QEMU <br>
GNU Arm Embedded Toolchain <br>
make <br>
GDB <br>
A Linux PC (or Windows with WSL) <br>
A phone with a Qualcomm Snapdragon 845 processor (test with CPU-Z) <br>
